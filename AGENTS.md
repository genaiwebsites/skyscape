# Agent Behavioral Rules

## STRICT GIT PROTOCOL (MANDATORY)
1. **NEVER run `git commit` under any circumstances** unless the USER explicitly requests a git commit in their prompt (e.g., "commit", "commit the code").
2. **NEVER run `git push` under any circumstances** unless the USER explicitly requests a git push in their prompt (e.g., "push", "push the code").
3. Always wait for explicit, unequivocal user authorization before running any git commit or git push commands.
